导入本地 osu! stable 回放 (.osr) 与谱面 (.osu)

📋 最近一次导入结果
    💡 绑定本地 osu! 根目录自动监听说明 File System Access API

    点击顶部 「绑定本地 osu! 根目录」 并选择你的 osu! 安装文件夹后，本应用会：

    • 读取 osu!.db 建立「谱面 MD5 → Songs 文件」索引，回放需要哪张谱面就按需从 Songs/ 读取哪张；
    • 记录 Data/r/ 与 Replays/ 中已有的回放作为基线（不会自动导入历史成绩，可用顶栏按钮按需导入），之后每 3 秒检查一次新文件并自动导入；
    • macOS 上 stable 通常位于 /Applications/osu!.app/Contents/Resources/drive_c/Program Files/osu!/，选择框里可按 ⌘⇧G 直接输入路径。
